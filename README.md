# VK-VPN — прокси-туннель через API ВКонтакте

Трафик браузера → локальный прокси → VK API → бот на сервере → целевой сайт

```
Браузер ──► client.py ──► VK API ──► bot.py ──► Интернет
  8080        (локально)              (сервер)
```

---

## Быстрый старт

### 1. Установка зависимостей (везде)
```bash
pip install -r requirements.txt
```

### 2. Настройка токенов — `config.py`

| Поле | Где взять |
|------|-----------|
| `GROUP_TOKEN` | Управление сообществом → Работа с API → Ключи (право: messages) |
| `USER_TOKEN` | https://vkhost.github.io/ → Kate Mobile → скопировать `access_token` из URL |
| `GROUP_ID` | ID твоей группы (без минуса) |
| `ALLOWED_USER` | Твой числовой VK ID |

### 3. Запуск бота (на сервере с нормальным интернетом)
```bash
python bot.py
```

### 4. Запуск клиента (локально)
```bash
python client.py
```

### 5. Настройка браузера
Выстави HTTP-прокси: `127.0.0.1:8080`

Firefox: Настройки → Прокси → Ручная настройка → HTTP: 127.0.0.1, порт 8080

## Архитектура протокола

### Запрос (client → bot через ВК)
```
VPN_REQ|<req_id>|<METHOD>|<url>|<headers_base64>|<body_base64_or_NONE>
```

### Ответ (bot → client через ВК, возможно несколько сообщений-чанков)
```
VPN_RES|<req_id>|<status>|<total_chunks>|<chunk_idx>|<resp_headers_b64_or_CONT>|<data_base64>
```

### Ошибка
```
VPN_ERR|<req_id>|<сообщение об ошибке>
```

## Ограничения

- **HTTPS не поддерживается** (только HTTP). Для HTTPS нужно добавить CONNECT-туннелирование с подменой сертификатов (mitmproxy-подход).
- **Скорость низкая** (~5–30 сек на страницу) из-за задержек VK API.
- **Картинки и бинарные файлы** передаются через base64 — медленно и увеличивают трафик на 33%.
- **Лимиты VK**: ~3 сообщения/сек; большие страницы дробятся на много чанков.
- **Подходит для**: текстовых страниц, API-запросов, небольших файлов.
